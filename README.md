# AmneziaWG (AWG) Web Management Panel & Xray TProxy

Современная, быстрая и легкая веб-панель для управления серверными подключениями **AmneziaWG**, маршрутизацией трафика в **Xray (TProxy)** и базой пользователей с персональными подсетями.

Разработана специально для удобного развертывания и администрирования на **Linux VPS** (Ubuntu 20.04 / 22.04 / 24.04, Debian 11 / 12).

---

## ✨ Основные возможности

### 1. Управление подключениями AmneziaWG (Интерфейсы)
- **Изолированные каталоги и симлинки**: для каждого подключения создается каталог `/etc/amnezia/amneziawg/awg*/`, внутри него конфигурационный файл `awg*.conf` и симлинк в `/etc/amnezia/amneziawg/awg*.conf`.
- **Поддержка протоколов AWG 1.0, AWG 2.0 и AWG 3.1**:
  - **AWG 1.0**: параметры обфускации `Jc`, `Jmin`, `Jmax`, `S1`, `S2`, уникальные 32-битные `H1`–`H4`.
  - **AWG 2.0**: расширенные параметры + `S3`, `S4`, поддержка CPS-сигнатур.
  - **AWG 3.1**: максимальная защита с `HeaderProtectionKey` (ChaCha20 в base64), диапазоны `ContentPaddingAddition`, `RandomTrailers`, сбалансированные `S1`–`S4`.
  - Автогенерация криптографических ключей Curve25519 и параметров обфускации в один клик.
- **Подсети 10.x.0.0/16**: параметр `x` указывается при создании подключения.
- **Маршрутизация в XRAY TProxy**:
  - Пользователь задает порт входящего инбаунда Xray (например, `7010`).
  - **Автоматический инкремент таблиц**: если есть таблица `101`, следующая создается с номером `102`, затем `103` и так далее.
  - Метки трафика `fwmark` назначаются последовательно без пересечений.
  - Генерация точных правил `PostUp` и `PostDown` с `RETURN` для локальной подсети `10.x.0.0/24`.
- **Контроль статуса**: запуск, остановка, перезапуск и удаление интерфейсов прямо из веб-интерфейса.

### 2. База пользователей и клиентских конфигураций
- **Иерархическая структура**: пользователи привязываются к выбранному подключению AWG.
- **Персональные подсети `10.x.y.0/24`**: каждому пользователю присваивается свой порядковый номер `y` (например, первый пользователь получает `10.x.1.0/24`, второй — `10.x.2.0/24`).
- **Множество устройств для одного пользователя**: внутри подсети создаются клиенты `10.x.y.1`, `10.x.y.2`, `10.x.y.3` и т.д.
- **Ярлыки устройств**: удобные метки («iPhone», «Рабочий ноутбук», «Роутер Keenetic»).
- **Экспорт**:
  - 📱 **QR-код**: отображение QR-кода прямо в браузере для сканирования в приложении AmneziaVPN / AmneziaWG.
  - 📥 **Скачивание .conf**: файл конфигурации с автоматическим именем `имя_ярлык.conf`.
  - 📋 **Быстрое копирование** конфигурации в буфер обмена.
  - 🔄 **Горячее обновление**: при добавлении или удалении пира туннель не падает, параметры синхронизируются на лету.

### 3. Интерфейс и удобство
- Две основные раздельные вкладки: **«Подключения AWG»** и **«Пользователи и Конфиги»**.
- Вкладка **«Настройки и Сервер»** с автоопределением внешнего IP, настройкой DNS и системным мониторингом.
- Адаптивный дизайн в темной теме.

## 🚀 Быстрая установка на VPS (в 1 команду)

Подключитесь к вашему новому или чистому Linux VPS по SSH под пользователем `root` и выполните:

```bash
curl -sSL https://raw.githubusercontent.com/fitz287/awg-manager/main/install.sh | bash
```

Скрипт полностью **автономен** и автоматически:
1. Проверит версию ОС (Ubuntu 20.04+, Debian 11+) и архитектуру.
2. Установит необходимые пакеты (`python3`, `python3-venv`, `iptables`, `curl`, `qrencode`, репозиторий `ppa:amnezia/ppa` и `amneziawg-tools`).
3. Включит IP-форвардинг в ядре Linux (`net.ipv4.ip_forward=1`).
4. Развернет файлы панели в каталог `/opt/awg-manager` и настроит Python venv.
5. Инициализирует базу данных SQLite и создаст конфигурацию `.env`.
6. Настроит и запустит системную службу `systemd` (`awg-manager.service`).
7. Установит консольную утилиту `awg-manager` для управления из терминала.
8. Выведет ссылку для входа в панель (`http://<IP_СЕРВЕРА>:8090`) и данные администратора (логин: `admin`, пароль: `password`).

## 🛠 Управление панелью через консоль

После установки на сервере доступна удобная CLI-утилита `awg-manager`:
```bash
awg-manager status          # Проверить статус службы
awg-manager restart         # Перезапустить панель
awg-manager logs            # Просмотр логов в реальном времени
awg-manager reset-password  # Сменить логин/пароль администратора
awg-manager set-port 8090   # Изменить порт панели
awg-manager info            # Показать адрес панели и статус
awg-manager uninstall       # Полное удаление панели с сервера
```

### 🗑 Удаление панели
Удалить панель можно в любой момент командой:
```bash
awg-manager uninstall
```
Либо одной командой через curl:
```bash
curl -sSL https://raw.githubusercontent.com/fitz287/awg-manager/main/scripts/uninstall.sh | bash
```

## ⚙️ Установка AmneziaWG на сервер (если еще не установлен)

Для работы туннелей AmneziaWG на уровне ядра Linux на сервере должен быть установлен модуль AmneziaWG.

### Ubuntu / Debian:
```bash
# Добавление официального репозитория Amnezia:
add-apt-repository ppa:amnezia/ppa -y
apt update
apt install -y amneziawg amneziawg-tools
```

Проверить доступность утилиты можно командой:
```bash
awg --version
```

## 📡 Настройка входящего инбаунда в XRAY

В ваших конфигах AWG создаются правила TProxy вида:
```ini
PostUp = iptables -t mangle -A XRAY_TPROXY_3 -p tcp -j TPROXY --on-port 7010 --tproxy-mark 3/3
PostUp = iptables -t mangle -A XRAY_TPROXY_3 -p udp -j TPROXY --on-port 7010 --tproxy-mark 3/3
```

В файле конфигурации Xray (`config.json`) в секции `inbounds` добавьте соответствующий TProxy инбаунд на указанный порт (например, `7010`):

```json
{
  "inbounds": [
    {
      "tag": "tproxy-in",
      "port": 7010,
      "protocol": "dokodemo-door",
      "settings": {
        "network": "tcp,udp",
        "followRedirect": true
      },
      "streamSettings": {
        "sockopt": {
          "tproxy": "tproxy"
        }
      }
    }
  ]
}
```

## 💻 Локальный запуск (для проверки и разработки)

Панель имеет встроенный Mock-режим: при запуске на Windows или macOS она не пытается вызывать системные команды Linux (`iptables`, `awg-quick`), а сохраняет конфиги в локальную папку `./data/amneziawg/`.

```bash
# Создание виртуального окружения
python -m venv venv

# Активация окружения (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# Установка зависимостей
pip install -r requirements.txt

# Запуск
python run.py
```

После запуска откройте браузер по адресу: `http://localhost:8080`.
